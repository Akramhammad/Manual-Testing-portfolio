# Manual-Testing-portfolio
Includes Test Cases for Signup Flow &amp; Reproducible Bug Reports for QA cart Free Demo


This repository contains manual testing documentation for a sample web application.

## 📁 Included Documents
- **Signup Test Cases:** Detailed functional and boundary test cases covering the User Registration flow (`Checklist1.xlsx`).
- **Bug Reports:** Reproducible defect logs with clear steps, severity, priority, and expected vs. actual results (`Bug report1.xlsx`).

## 🧪 Tools & Methodologies Used
- Manual Testing & Exploratory Testing
- Boundary Value Analysis (BVA) & Equivalence Partitioning (EP)
- Defect Tracking & Documentation
